# Entregable I - Calculadora

## Funcionalidades

* Leer dos números ingresados por el usuario.
* Realizar una suma.
* Realizar una resta.
* Realizar una multiplicación.
* Realizar una división.
* Validar la división entre cero.
* Validar que los valores ingresados sean números válidos.
* Repetir operaciones mediante un menú.
* Permitir al usuario salir de la aplicación.

---

## Validaciones
* Valida que el número ingresado sea válido.
* Valida que la división no sea entre cero.
